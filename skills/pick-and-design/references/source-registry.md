# Source registry

Checked 2026-10-11. This is a routing index of 40 user-selected URLs. Page inspection means public page text/metadata was read, not that all examples, visual assets or interactions were reviewed. Access outcomes describe this research tool at this date, not permanent site availability. Tracking parameters removed. Revisit relevant pages and inspect actual rendered references during the design task.

## Choose by need

- Site direction: Awwwards for award-led discovery and interaction references; Curated, Minimal Gallery, Land-book, SEESAW, Recent, One Page Love; SaaS-specific discovery can use Saaspo, SaaSFrame and Landingfolio.
- Web workflows: Mobbin, Pageflows, SaaSFrame, Morphin. Filter out native mobile references.
- Section work: Supahero, Navbar Design, Navbar Gallery, Footer Design, UI Sections. A section gallery is not evidence of full-flow usability.
- Visual world: inspect Imageory before use; Venust for candidate backgrounds, UI Camera for software presentation. Do not add imagery solely because a source exists.
- Motion and implementation: Loading.dev, Kugiri, Beautiful UI, Magic UI; examine exact docs and rendered behavior.
- Craft and reasoning: Interfaces, UI Playbook, Practical Typography, Refactoring UI and relevant reading below. Editorial advice is contextual; accessibility standards are handled by the UX module.

Use Designeer as discovery support and YC/company/investor primary sources for startup evidence. These complement the supplied pool. No source is mandatory for every request. Search relevant libraries, open candidate details and original sites, then cite the actual reference used. If blocked, try an available browser or official public material; report remaining gaps and move to an appropriate alternative.
